# Codex Pulse · Codex 额度悬浮球

一个在 macOS 桌面置顶的轻量监控工具，用来查看本机 Codex 的 **5 小时剩余额度、周剩余额度和工作状态**。

科技仪表风设计：蓝色外环表示短周期额度，紫色内环表示周额度。Codex 工作时，球面、外沿光晕和双光环同步呼吸，“工作中”以亮色状态牌突出显示。

![悬浮球预览](preview.png)

## 功能

- **双额度显示**：直接显示短周期、长周期剩余百分比；周期长度以日志数据为准。
- **工作状态**：区分工作中、空闲、待确认和连接断开。
- **呼吸灯**：工作时约每 3 秒完成一次明暗变化，空闲或断开时停止；遵循 macOS「减少动态效果」设置。
- **小巧置顶**：球体直径 90 点，支持跨桌面显示、拖动移动。
- **点击展开**：查看额度重置时间、日志采样时间等详情。
- **右键菜单**：手动刷新、退出。
- **本地读取**：不需要 API Key，不上传会话数据。

## 环境要求

- macOS，已在本机 macOS 27 环境编译验证；其他系统版本尚未验证。
- 已安装并使用 Codex，存在本机会话日志。
- Python 3.9 或更高版本；启动 App 时需能通过 `/usr/bin/env python3` 找到 Python。
- 从源码构建需要 Xcode Command Line Tools（提供 Swift 编译器）。

## 从源码构建

```bash
bash build.sh
```

产物：

```text
build/Codex Pulse.app
build/Codex Pulse.zip
```

将 `Codex Pulse.app` 拖到「应用程序」后双击打开。数据服务和页面资源已经打包在 App 内，无需启动 `.command` 脚本，也无需保持终端打开。

本项目面向个人本机使用，采用本机临时签名，未进行 Apple Developer ID 签名或公证。二进制默认针对构建电脑的架构生成。

## 使用方法

1. 打开 Codex 并运行一次任务，让 Codex 生成额度日志。
2. 双击 `Codex Pulse.app`，悬浮球出现在屏幕右上方。
3. 拖动悬浮球调整位置；点击展开或收起详情。
4. 右键选择「退出悬浮球」关闭应用。

服务默认监听 `127.0.0.1:8765`。浏览器打开 <http://127.0.0.1:8765> 也可以查看完整面板；原生 App 不依赖浏览器。

## 数据如何更新

每 3 秒读取一次本地服务。服务增量解析 `$CODEX_HOME/sessions` 下的 JSONL 文件；未设置 `CODEX_HOME` 时默认读取 `~/.codex/sessions`。

| 显示内容 | 数据来源与规则 |
| --- | --- |
| 短周期、周额度 | 扫描范围内最新 `token_count.rate_limits.primary` 与 `secondary`，剩余百分比为 `100 - used_percent` |
| 重置时间 | 日志中的 `resets_at`，到期后等待新采样，不自行恢复为满额度 |
| 工作中 | 最近任务事件为 `task_started`，且对应日志最近 180 秒内有更新 |
| 空闲 | 观察到 `task_complete`、`task_completed` 或 `turn_aborted` |
| 待确认 | 任务尚未结束，但超过 180 秒没有新日志 |
| 离线 | 本地数据服务无法连接 |

**刷新界面不等于主动请求账户服务器。** 额度数字跟随 Codex 写入的日志更新；采样时间可在详情中查看。

## 隐私和限制

- 只扫描最近修改的 80 个会话文件，不修改 Codex 数据。
- 本地 HTTP API 仅提供额度、模型、会话标识和用量统计，不返回聊天正文或凭据。
- 工作状态由日志推断，并非操作系统级进程探测。长工具调用、等待授权或异常退出可能显示为待确认。
- 多账户共用同一日志目录时不能可靠区分账户，建议使用独立 `CODEX_HOME`。
- Codex 日志格式属于实现细节，未来版本变更可能需要适配。
- 本项目是独立的本地辅助工具，不是 OpenAI 官方产品，也不是修改 Codex 客户端的插件。

## 源码结构

```text
Float.swift   # 原生 AppKit 悬浮窗、额度绘制、呼吸动画及交互
server.py     # Python 标准库 HTTP 服务与增量日志解析
index.html    # 可选的完整网页仪表盘
Info.plist    # macOS App 元信息
build.sh      # 本机构建、签名和打包脚本
preview.png   # 界面预览
```

## 单独调试数据服务

```bash
python3 server.py
# 端口冲突时
python3 server.py --port 8766
```

悬浮球默认连接 8765，若更改服务端口，也需要同步修改 `Float.swift` 中的请求地址并重新构建。
